# LJT-Homepage

Personal academic homepage of **Junteng Liu**, a first-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology (HKUST).

The site is built with [AcademicPages](https://github.com/academicpages/academicpages.github.io), a Jekyll template for academic websites (itself a fork of [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes)).

## Site content

- `_pages/about.md` — home / about page (personal details, research interests, education, research experience, publications, skills, honors and awards, contact)
- `_pages/publications.html` — the publications listing page
- `_publications/` — one file per publication, rendered on the publications page
- `_config.yml` — site and author configuration
- `_data/navigation.yml` — top navigation menu

## Running locally

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

Then open `http://localhost:4000`.
